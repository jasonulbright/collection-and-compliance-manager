# Keyboard

This page lists the Tab order and the keys of Collection and Compliance Manager.

## What it does

Every control can be reached with the keyboard. A focus frame shows the control that has the focus.

## When to use it

Use it to work without a mouse.

## Requirements

None.

## Steps

### Tab order of the Collections view

Select the **Collections** button in the sidebar, then press Tab. The focus goes in this order:

1. The sidebar buttons: **WQL Editor**, **Templates**, **Catalog**, **Live CI/CB**, **Editor**, **Auditing**, **Options**.
2. **Refresh**.
3. The filter box and the shape list.
4. **Export CSV** and **Export HTML**.
5. The grid, one cell after the other. The action buttons below the grid follow.

### Keys

| Key | Effect |
|---|---|
| Tab, Shift+Tab | Move the focus. |
| Enter, Space | Press the focused button. |
| Up, Down | Move in a grid, a list or a tree. |
| Esc | Close a dialog, as **Cancel**. |

## Limits

- The Tab order of the other views follows the layout: the sidebar, the action bar, the filters and the grid.

## Troubleshooting

| Message or symptom | Cause | Fix |
|---|---|---|
| A button is skipped. | The button is disabled. | Select a row first. |
